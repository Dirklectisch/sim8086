# sim 8086

A machine code to assembly language decoder written in Zig.

# Usage

Try it out

````
zig run ./src/cli.zig -- vendor/computer_enhance/perfaware/part1/listing_0041_add_sub_cmp_jnz
````

(requires you have a working Zig compiler)
